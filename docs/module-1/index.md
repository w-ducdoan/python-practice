# Module 1 - Values and variables

[Back to Home](../index.md)

**Objective:** do finance math in Python, store results under names you can reuse, and format money and percentages for a reader.

**Time:** about 2.5 hours, over four sessions.

| Lesson | What you learn |
| :-- | :-- |
| [1.1 Numbers and arithmetic](1-1-numbers.md) | Math operators, order of operations, the Excel `^` trap, rounding |
| [1.2 Variables](1-2-variables.md) | Naming values, reusing them, updating them |
| [1.3 Text and formatting](1-3-strings.md) | Strings, f-strings, money and percent formats, converting types |
| [1.4 True and False](1-4-booleans.md) | Comparisons, `and` / `or` / `not`, covenant-style tests |
| [1.5 Capstone - loan payment](1-5-capstone.md) | Put it together: a mortgage and a term loan |
| [Checkpoint 1](checkpoint.md) | Prove it: a bond price and a terminal value, no hints |

**Optional reading:** CS50P Lecture 0 at [cs50.harvard.edu/python](https://cs50.harvard.edu/python/), the Python basics chapter of *Automate the Boring Stuff* at [automatetheboringstuff.com](https://automatetheboringstuff.com/).
