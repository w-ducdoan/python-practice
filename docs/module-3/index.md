# Module 3 - Loops, lists and dictionaries

[Back to Home](../index.md)

**Objective:** hold many values at once (a cash flow stream, a price series, a loan tape) and repeat a calculation over all of them, which is what turns one-off math into a model.

**Time:** about 4 hours, over five or six sessions.

| Lesson | What you learn |
| :-- | :-- |
| [3.1 Lists](3-1-lists.md) | Storing a series, indexing from 0, slicing, `len` / `sum` / `min` / `max`, `append` |
| [3.2 For loops](3-2-for-loops.md) | Repeating work, running totals, `range`, `enumerate`, building new lists |
| [3.3 Dictionaries](3-3-dicts.md) | Lookup tables, `.get` with a default, looping over `.items()`, counting |
| [3.4 Tables as lists of dicts](3-4-records.md) | A loan tape in plain Python: filter, total, weighted average, group by |
| [3.5 While loops and loop control](3-5-while.md) | Repeat-until loops, `break`, `continue`, avoiding loops that never end |
| [3.6 Capstone - amortization schedule](3-6-capstone.md) | A full schedule, a summary, and an early-paydown scenario |
| [Checkpoint 3](checkpoint.md) | Prove it: sector weights and payback period, no hints |

**Optional reading:** CS50P Lecture 2 (loops) at [cs50.harvard.edu/python](https://cs50.harvard.edu/python/), and the lists and dictionaries chapters of *Automate the Boring Stuff* at [automatetheboringstuff.com](https://automatetheboringstuff.com/).
