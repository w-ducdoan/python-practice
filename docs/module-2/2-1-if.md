# 2.1 Making decisions

[Module 2](index.md) · about 35 minutes

## The idea

In Module 1 you calculated `breach = leverage > max_leverage`, which gives `True` or `False`. Now you'll make the program **do different things** depending on that answer. It's Excel's `IF`, written as a block:

```python
if leverage > max_leverage:
    status = "BREACH"
else:
    status = "PASS"
```

- The line starts with `if`, then a condition, then a **colon**.
- The lines that belong to the `if` are **indented** 4 spaces (press Tab). Python uses the indentation to know where the block ends. Indentation isn't decoration here, it's how Python reads the code. Get it wrong and you'll see a new error: `IndentationError`.
- `else:` catches everything the `if` didn't.

For more than two outcomes, add `elif` ("else if"). It works like a nested `IF` in Excel:

```python
if leverage <= 3.0:
    bucket = "Low"
elif leverage <= 5.0:
    bucket = "Moderate"
else:
    bucket = "High"
```

Python checks the conditions **top to bottom and stops at the first true one**. So order matters: put the narrowest test first. If `leverage <= 5.0` came first, a 2.0x credit would land in "Moderate" and never reach "Low."

One new tool: `abs(x)` gives the size of a number without its sign. `abs(-0.034)` is `0.034`.

**From here on, keep the input lines exactly as given.** The tests change those inputs (say, `leverage = 5.6` becomes `leverage = 3.0`) and run your code again, to make sure it works for any input, not just the one on screen.

spread_bps = 720

spread_bps = 720

**5.** Build a one-line performance label. A return of -0.034 should give `"Down 3.4% YTD"`, 0.12 should give `"Up 12.0% YTD"`, and exactly 0 should give `"Flat YTD"`. Use an f-string with a percent format.

```exercise
id: m2-ytd-label
title: Up, down or flat
--- starter
ytd_return = -0.034

--- tests
check(label == "Down 3.4% YTD", f"-0.034 should give 'Down 3.4% YTD' (yours: {label!r})")
ns = rerun("ytd_return = -0.034", "ytd_return = 0.12")
check(ns["label"] == "Up 12.0% YTD", f"0.12 should give 'Up 12.0% YTD' (yours: {ns['label']!r})")
ns = rerun("ytd_return = -0.034", "ytd_return = 0")
check(ns["label"] == "Flat YTD", f"0 should give 'Flat YTD' (yours: {ns['label']!r})")
--- hint
Three outcomes: > 0, < 0, and everything else.
--- hint
For the down case, use abs(ytd_return) inside the f-string so the minus sign disappears: {abs(ytd_return):.1%}
--- solution
ytd_return = -0.034

if ytd_return > 0:
    label = f"Up {ytd_return:.1%} YTD"
elif ytd_return < 0:
    label = f"Down {abs(ytd_return):.1%} YTD"
else:
    label = "Flat YTD"
```

## Explain it back

A credit has 2.0x leverage. Your code checks `elif leverage <= 5.0` **before** `leverage <= 3.0`. Which bucket does it land in, and why?

??? note "Model answer"
    "Moderate." Python checks conditions top to bottom and stops at the first true one. `2.0 <= 5.0` is true, so it never reaches the `<= 3.0` test. Put the narrowest condition first.
