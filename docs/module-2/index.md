# Module 2 - Functions and conditionals

[Back to Home](../index.md)

**Objective:** make code choose between paths with `if`, and package calculations into reusable functions you can run on any borrower, bond or deal.

**Time:** about 3 hours, over four or five sessions.

| [2.1 Making decisions](2-1-if.md) | `if` / `elif` / `else`, indentation, why order matters |
| [2.2 Functions](2-2-functions.md) | `def`, parameters, `return`, and why `return` is not `print` |
| [2.3 Decisions inside functions](2-3-decision-functions.md) | Early returns, default values, `None` for "no answer," edge cases |
| [2.4 Building with functions](2-4-building.md) | Functions that call functions, scope, returning two values |
| [2.5 Capstone - covenant tool](2-5-capstone.md) | A covenant compliance checker with headroom and EBITDA cushion |
| [Checkpoint 2](checkpoint.md) | Prove it: a DSCR test and a rate-shock report, no hints |
